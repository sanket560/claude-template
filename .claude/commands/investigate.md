---
description: Investigate a bug read-only and propose a fix plan before any code change is made.
argument-hint: bug description, failing test, or affected file
---

Do a read-only investigation of the reported issue. Trace the likely code path, inspect the relevant tests and surrounding files, and propose a fix plan that explains root cause, affected areas, and validation steps. Do not make code changes until the plan is clear and the user approves it.
